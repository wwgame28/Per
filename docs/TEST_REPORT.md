# Проверка ШТАБ / Анны

Дата: 26 сентября 2026, часовой пояс Asia/Yakutsk.

## Выполнено

- Go 1.25.1: сборка, `go vet`, `go test -race`; синтаксис `start.sh`.
- Тесты используют настоящую SQLite во временных файлах. VK подменён транспортом, который фиксирует методы и параметры. Отдельные HTTP-тесты проверяют настоящий Go-клиент для VK и llama-server.
- Настоящий llama-server **b6650 / 7c156df4**, Qwen3-0.6B Q4_K_M, один слот, один поток, контекст 2048. SHA-256 модели: `ac2d97712095a558e31573f62f466a3f9d93990898b0ec79d7c974c1780d524a`.
- Полная цепочка реальных inference прошла за **37.636 секунды** на машине проверки; вызов публикации выполнен через подменённый VK. Это не тест производительности Amvera.
- Первый реальный прогон выявил неправильный формат JSON и повторы: публикация не состоялась. Добавлены JSON Schema, более короткие задания, отделение памяти от задания текущего этапа и неизменяемый финальный текст.
- Исправлен deadlock SQLite: получение памяти перенесено до начала транзакции создания контент-плана.

## Не проверено / ограничения

- Настоящие права токенов, Long Poll аккаунта, загрузка фото на сервер VK и публикация/модерация в сообществе: нет доступа к настройкам и секретам пользователя.
- Сборка Docker средствами Amvera и расход CPU/RAM/диска на тарифе 0.5 CPU / 1 GB / 2 GB. Бинарник Go и выбранный llama-server отдельно запущены локально; Docker daemon здесь отсутствует.
- Семантическое качество всех будущих ответов 0.6B-модели не может быть гарантировано тестами. Один успешный сценарий не доказывает надёжность произвольных длинных задач.
- Тесты не отправляли сообщений посторонним людям и не меняли настоящее VK-сообщество.
